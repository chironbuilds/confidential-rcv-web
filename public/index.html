Elections

How it works

01

Add voters

Paste wallet addresses. Each one gets exactly one stealth ballot token, minted on-chain in a single transaction.

02

Vote privately

Voters rank the candidates from their own wallet. The ballot is spent with a one-time key and the fee is paid privately, so nothing links it back.

03

Count on-chain

The template runs the runoff itself. Every round is public, so anyone can verify the result without trusting this site.
